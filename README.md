# PB1_PD16 – Git un GitHub praktiskais darbs

Šis ir praktiskais darbs, kura mērķis ir apgūt Git versiju kontroli un GitHub izmantošanu.

## Projekta saturs

Projektā ir šādi faili:
- `projekts.py` – vienkāršs Python skripts, kas tika izmantots Git darbību demonstrēšanai.
- `.gitignore` – fails ignorējamo failu definēšanai.
- `README.md` – projekta apraksts.

## Veiktās Git darbības

- Inicializēts Git repozitorijs (`git init`)
- Izveidots pirmais commit
- Izveidots zars `feature-uzlabojums`
- Veiktas izmaiņas un commit jaunajā zarā
- Zars apvienots ar `main` (`git merge`)
- Izveidots zars `konflikts`
- Simulēts merge konflikts, mainot vienu un to pašu rindu abos zaros
- Konflikts atrisināts manuāli
- Projekts augšupielādēts GitHub repozitorijā

## Mērķis

Demonstrēt Git pamata darbības:
- commit
- branch
- merge
- konflikta risināšana
- GitHub integrācija
